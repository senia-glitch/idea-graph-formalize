# Формализация требований

Пакет-скилл. Превращает принятые решения в карточки «требование» с кодом (`FR-1`), приоритетом и
критериями приёмки. Вопрос задаёт только там, где решение можно понять по-разному.

## Установка

```
pip install -e .
```

Нужны `ideagraph-core` и `ideagraph-shell`.

## Тесты

```
pip install pytest
python -m pytest
```
